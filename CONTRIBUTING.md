# Contributing to Express Starter CLI 🚀

Thanks for considering contributing to **Express Starter CLI**, a fast way to bootstrap a Node.js + Express.js + MongoDB project! All kinds of contributions are welcome: code, documentation, feature requests, bug reports, and reviews.

## How to Contribute

**1. Fork the repository**  
Click the _Fork_ button at the top right to get your own copy.

**2. Clone your fork locally**
```bash
git clone https://github.com/aniketraut16/express-starter-cli
```

**3. Create a branch for your changes**
```bash
git checkout -b feature/my-feature
```

**4. Make your changes**  
Follow edits with clear, conventional commit messages.

**5. Test your code**  
Make sure everything runs well and your changes don't break existing functionality.

**6. Push your branch to GitHub**
```bash
git push origin feature/my-feature
```

**7. Open a Pull Request**  
Go to your fork’s page, and click "New Pull Request".  
Describe clearly **what** you changed and **why**.

## Types of Contributions

- **Bug Fixes:** Help squash bugs!  
- **Features:** Add new functionality that helps users scaffold their projects.  
- **Documentation:** Improve clarity, examples, or translation.
- **Tests:** Add or improve unit/integration tests.
- **Refactoring:** Clean up, update dependencies, or improve the code structure.
- **Feedback:** Open issues for feature requests or suggestions.

## Issue Guidelines

- Before submitting a new bug or feature, check for existing issues.
- Use clear, descriptive titles and step-by-step instructions.
- If submitting a bug, include error output, CLI command used, Node version, and OS info.

## Code Style

- Use modern JavaScript (ES6+)  
- Semicolons preferred  
- Format code with [`prettier`](https://prettier.io/) for consistency  
- Keep code modular (split logic across files/folders where possible)

## Pull Request Guidelines

- One fix/feature per Pull Request (PR)
- Reference related issues in the PR description (e.g., `Fixes #24`)
- Include tests for new/updated functionality
- Add/update documentation if necessary
