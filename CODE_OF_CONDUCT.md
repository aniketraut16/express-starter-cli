# Code of Conduct

## Preamble

As contributors and maintainers of **Express Starter CLI**, we encourage a **welcoming, respectful, and inclusive** environment for everyone, regardless of experience level, background, or identity.

## Our Standards

**Examples of positive behavior:**
- Using inclusive, respectful language
- Patience with new contributors
- Accepting constructive criticism gracefully
- Adding clear documentation and code comments
- Offering support and guidance

**Examples of unacceptable behavior:**
- Harassment, abuse, or intimidation
- Discrimination or offensive comments (race, gender, etc.)
- Public or private threats or derogatory remarks
- Sharing personal or confidential information without consent

## Maintainer Responsibilities

Maintainers will investigate all reports of unacceptable behavior and take appropriate action (removal, ban, editing, etc). All complaints will remain confidential.

## Scope

This Code applies to all repository spaces: issues, pull requests, code reviews, discussions, or private communications involving the project.

## Reporting

If you experience or witness unacceptable behavior, please report it to the maintainer (`rautnaniket@gmail.com` or open an issue marked "confidential"). All reports are taken seriously.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.
